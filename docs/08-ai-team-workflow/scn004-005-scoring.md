# SCN-004·005 로컬 Rule/ML 평가 근거

R011/R012는 완전성 Mock과 현재 거래를 포함한 cutoff 고정 승인 이체 창에서만 25점을 낸다. 집계 두 신호의 공통 채택 한도는 40점이다. 기존 R001–R010 의미와 ML v3 아티팩트는 변경하지 않는다. 새 ML v4는 v3의 12개 feature와 두 집계 이진 feature를 사용한다. 가중치는 v3 기준선에 두 집계 feature 각각 0.55를 더한 **수작업 합성 기준선**이며 학습 성능 향상 주장이 아니다. `fraud_model_v4.json` 및 manifest의 SHA-256으로 모델을 고정한다.

합성 검증은 증명된 두 창에서 모델 출력이 증명 없는 창보다 커지는지, 이력 불명과 계약 누락이 위험 적중으로 바뀌지 않는지 확인한다. 5,000bp 초과 최대 40점 원기여를 계산하고, 정상 다건 정산·집금에서 독립 신호가 없으면 최종 점수를 49점 이하로 제한한다. 재현 테스트는 계약/역순/시각 경계/버전 고정을 확인한다. 실제 금융 운영 자료에서의 정밀도·재현율·오탐률은 측정하지 않았다.
