# SCN-008 로컬 Rule/ML 근거

R015는 승인된 외부 오픈뱅킹 원천 거래가 서로 다른 검증된 Mock 외부 계좌 2개 이상에서 같은 고객의 집금 계좌로 들어온 뒤, 명시적 방향 링크로 최종 재송금에 연결되는 경우에만 50점 원점수를 낸다. 30분 집금·15분 재송금, 집금 500만 KRW 이상, 재송금/집금 8000bp 이상은 포트폴리오용 합성 경계다. 독립 위험 신호가 없으면 자금 흐름 신호만으로 CRITICAL이 되지 않도록 Rule/ML 적용 상한을 79점으로 둔다. 정상적인 부분 재송금과 증명되지 않은 같은 계좌 거래는 신호에 넣지 않는다.

Rule v7의 15개 기여와 7개 그룹은 backend가 독립 재계산한다. ML v6은 기존 16개 feature에 검증된 오픈뱅킹 체인 이진 feature 하나를 추가한 수작업 합성 logistic 기준선이다. 신규 feature 가중치 0.85는 훈련 성과가 아니라 로컬 재현 테스트용이다. 모델 JSON과 manifest의 SHA-256을 고정하며 기존 완료 결과의 Rule/ML 버전과 점수는 재계산하지 않는다. 실제 금융 운영 정밀도·재현율·오탐률·성능은 측정하지 않았다.
