# 프로젝트 개요

## 프로젝트명

AI Fraud Detection Platform

## 한 줄 설명

금융 거래 데이터를 기반으로 이상거래를 탐지하고, 생성형 AI를 활용해 탐지 사유와 대응 리포트를 제공하는 운영 플랫폼

## 개발 목적

금융권 서비스에서 중요한 이상거래 탐지 과정을 직접 구현하고, 백엔드 API, AI 분석 서비스, 클라우드 배포, 모니터링까지 포함한 end-to-end 시스템을 구축한다.

## 주요 사용자

- 운영 관리자
- 보안/리스크 담당자
- 금융 서비스 운영팀

## 핵심 가치

- 거래 이상 징후 탐지
- 탐지 사유 설명 가능성
- 운영자가 확인할 수 있는 대시보드
- 클라우드 기반 배포 및 모니터링
