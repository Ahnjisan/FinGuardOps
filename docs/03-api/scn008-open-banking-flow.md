# SCN-008 로컬 오픈뱅킹 다단계 흐름 계약

이 계약은 합성 거래와 로컬 Mock 증명에만 적용한다. `POST /api/v1/fds-mock-open-accounts`는 외부 계좌의 고객 등록·소유 주장 상태(`VERIFIED`, `PARTIAL`, `FAILED`)와 고유 assertion ID를 불변 기록으로 접수한다. 요청은 정확히 `assertionId`(UUID v4), `externalCustomerRef`, `externalAccountRef`, `registrationState`, `ownershipState`, `occurredAt`(UTC)을 포함한다. 신규 접수는 201, 동일 요청 재시도는 200이며 응답은 `assertionId`, `sourceCode=LOCAL_OPEN_BANKING_MOCK`, `sourceVersion=v1`이다. 잘못된 요청은 400, ID·의미 충돌은 409이고 기존 Mock 접수 권한이 필요하다. 실제 금융기관 계좌 소유를 추정하지 않는다.

기존 `POST /api/v1/fds-mock-fund-links`에서 `SCN008` 연결은 대상 송금으로 향하는 각 원천 오픈뱅킹 거래에 대해 별도 접수한다. 승인된 원천의 고객과 집금 수취 계좌가 대상 송금의 고객·출금 계좌와 정확히 같아야 한다. 원천마다 별도 `VERIFIED` 외부 계좌 소유 Mock 증명이 필요하다. 동일 원천을 둘 이상의 후행 대상에 재사용하거나 같은 대상에 SCN-007 대출 원천 링크가 공존하면 자금 귀속을 확정하지 않는다. `PARTIAL`·`FAILED`·중복/충돌·늦은 접수와 이력 부족은 `UNKNOWN`으로 닫는다.

`POST /api/v6/rule-analysis`는 기존 v5 요청에 `openBankingFacts`를 더한 15개 Rule v7 계약이다. 이 사실은 `sourceVersion=SCN008-contract-v1`, `status`(AVAILABLE/UNKNOWN), `reasonCode`, `historyCoverageFactId`, `concentrationStartedAt`, `concentrationCompletedAt`, `concentrationAmount`, `resendAmount`, `ratioBasisPoints`, `stages`를 가진다. 각 stage는 `sourceTransactionId`, `ownershipAssertionId`, `linkId`, `occurredAt`, `approvedAt`, `amount`를 가진다. UNKNOWN에서는 증명 ID·시각·stage가 비고 금액·비율은 0이다. R015 `VERIFIED_OPEN_BANKING_CONCENTRATION_RESEND`는 외부 계좌 2개 이상에서 30분 안에 집금된 총액 500만 KRW 이상, 마지막 집금 후 15분 안에 최종 재송금, 재송금/집금액 8000bp 이상일 때만 맞는다. 원천 발생·생성·승인, Mock 증명 발생·생성 및 연결 접수는 평가 cutoff 이하여야 하며 원천 발생은 대상보다 앞서야 한다. `ACCOUNT_FLOW_HISTORY_COMPLETE`가 원천 집금 시작부터 평가 cutoff까지 덮어야 한다. 원천 거래 ID, 링크 ID, 소유 Mock assertion ID, coverage ID, 시각·금액·비율을 Evidence에 고정한다. 외부 원천 계좌 원문은 `openBankingFacts`, ML payload 및 채택 결과 조회에 전달하지 않는다. 기존 Rule 거래 스냅샷의 대상 송금 계좌 필드는 유지한다.

ML `POST /api/v1/ml-inference`의 추가 조합은 `rule-ml-policy-v6` / `fraud-feature-v5` / `fraud-logistic-v6` 및 고정 SHA-256 `707284450be52621a7ca00455eab9edfa74fbbef207efbf89ffc87267cd97383`이다. `openBankingFacts`가 빠지거나 다른 버전의 사실을 섞으면 거부한다. `GET /api/v1/transactions/{id}/adopted-detection-result`는 이 버전에서 `openBankingEvidence`를 반환한다. 상태, Mock 출처, cutoff, 원천별 증명 ID와 귀속된 금액이 보이며 완료된 이전 버전 결과는 재계산하지 않는다.
