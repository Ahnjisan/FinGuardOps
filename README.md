# AI-Financial-FDS-Platform
AI-based Financial Fraud Detection and Analysis Platform

## 프로젝트 개요

AI 기반 금융 이상거래 탐지 및 분석 운영 플랫폼입니다.  
가상 금융 거래 데이터를 기반으로 이상거래를 탐지하고, 생성형 AI를 활용해 탐지 사유와 대응 리포트를 제공합니다.

## 프로젝트 목표

- 금융 거래 데이터 기반 이상거래 탐지
- Spring Boot 기반 백엔드 API 설계 및 구현
- FastAPI 기반 AI 분석 서비스 구현
- React 기반 운영 대시보드 구현
- Docker, Kubernetes, CI/CD 기반 배포 환경 구성
- Observability 기반 운영 모니터링 구축

## 핵심 기능

- 거래 데이터 등록 및 조회
- 이상거래 위험 점수 산출
- 탐지 사유 자동 생성
- 관리자 대시보드
- 알림 및 대응 이력 관리
- 로그, 메트릭, 트레이싱 기반 운영 관찰

## 기술 스택

- Frontend: React, TypeScript
- Backend: Java, Spring Boot, JPA
- AI Service: Python, FastAPI
- Database: PostgreSQL, Redis
- DevOps: Docker, Kubernetes, GitHub Actions, AWS
- Monitoring: Prometheus, Grafana

## 개발 방식

생성형 AI를 역할별 개발 도구로 활용하여 개발 생산성을 높이고,  
요구사항 정의, API 및 데이터베이스 설계, 시스템 아키텍처 결정, 코드 검증, 테스트, DevOps와 배포는 직접 수행합니다.
